# Qalb — UX and Visual Guidelines

## Visual direction
- Calm, minimal, warm, and readable; avoid busy patterns or gamified pressure.
- Suggested palette: deep forest green, warm ivory, muted gold accents, neutral greys. Verify contrast in light and dark themes.
- Use consistent Material 3 components and spacing.
- Do not use decorative calligraphy for text that must be read exactly.

## Today screen
- Show each occasion as a separate section.
- Keep time-window groups visually distinct from prayer-triggered groups.
- Progress should be informative, not guilt-inducing.
- A skipped or not-yet-due item should not be styled as a religious failure.

## Dhikr detail
- Arabic text should be prominent, RTL-aware, selectable, and scaleable.
- Display transliteration and Bengali meaning separately.
- Clearly show required repetition count and source details.
- Show content verification state and distinguish user-created content.

## Tasbih
- Large central tap target, visible count and target.
- Undo must be accessible.
- Reset requires confirmation if it will discard a nonzero count.
- Optional vibration can be turned off.
- Do not make audio or vibration mandatory.

## Accessibility
- Test large font settings and Arabic shaping on a real Android device.
- Don't rely on colour alone to communicate a status.
- Use descriptive labels for screen readers.
- Handle narrow screens and landscape reasonably.
